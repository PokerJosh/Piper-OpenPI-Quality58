# Files Manifest

This is a selective source archive. It excludes upstream files not needed to
understand the Piper/OpenPI Quality58 changes and excludes all dataset/model
payloads.

## Included categories

- Quality58 model/data/policy implementation and focused tests.
- Direct Joint safety core, guarded runner, camera verifier, and tests.
- Offline evaluator and CPU/offline data utilities.
- Sanitized manifest and mask metadata examples.
- Final normalization statistics and provenance.
- Project plans, runner design, final status, reproducibility notes, and patches.
- Upstream license files.

## Excluded categories

- Checkpoint weights and serialized model state.
- Dataset episodes, parquet/pickle payloads, videos, images, raw captures, and
  runtime logs.
- Environment directories, caches, bytecode, and source Git metadata.
- Machine-specific paths, hardware serials, credentials, and private tokens.

The authoritative file list is the tracked file list in the archive Git commit.
